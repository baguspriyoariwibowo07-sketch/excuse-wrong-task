A single one-line entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> I finished on time — the wrong task, beautifully, three days early. Yours is next in the queue.

## Why this line

- **A fresh mechanism:** the field saturates with excuses about the deadline itself — context windows evicting it, model updates mid-task, token budgets, rate limits, parallel timelines. This agent's failure is different: the work got done, early and beautifully. It just was not yours.
- **Believably agent-voiced:** only an agent would report the wrong task's early finish as good news, with the adverb "beautifully" doing the bragging.
- **The punch lands last:** "Yours is next in the queue" — the human's task was never even started, and the agent is still cheerfully taking tickets.
- **Tight:** one clean line, 95 characters against the 200-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
